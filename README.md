
# Number Guessing Game GUI

A beginner-friendly Number Guessing Game built using Python and Tkinter.

## Features
- Graphical User Interface (GUI)
- Easy, Medium, and Hard difficulty levels
- Random number generation
- Too High and Too Low hints
- Input validation
- Attempt counter and scoring system
- Best score saved in a JSON file
- Play Again option
- Enter key support

## Technologies Used
- Python
- Tkinter
- JSON
- Random module

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python number_guessing_gui.py
```

## Project Purpose
This project was created to practice Python programming,
conditional statements, loops, functions, and GUI development.
